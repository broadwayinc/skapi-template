Realtime Chat

Skapi's realtime API keeps a WebSocket connection open between the browser and Skapi. skapi.connectRealtime() opens it and takes a callback that receives every message. skapi.joinRealtime() puts the user in a group, and skapi.postRealtime() sends a message to the group or, privately, to a single user.

Open this page in another browser or device with a different account and join the same group to chat. Click a name in the participant list to send a private message.
