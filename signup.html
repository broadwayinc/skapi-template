Sign up

skapi.signup() creates an account. Email address and password are required; the other fields (here, the name) become part of the user's profile.

With the signup_confirmation option Skapi sends a confirmation email, and the account can only log in after the link in it has been clicked. The option is set to the address of the login page, so the link brings the user there.
